# APP-COMMON-R1.6 — Global Revocation Enforcement (partial)
Status: PARTIAL CODE / NOT EXECUTED / S2 HOLD

## Implemented in this increment
- App Common's own JWT decoder now composes signature, issuer, audience and revocation validator.
- Revocation validator reads PostgreSQL on each authenticated request; explicit BLOCKED denies a previously issued JWT **at App Common API only**. PostgreSQL exceptions also deny (fail closed).
- Operation status lookup is scope-protected; R1.6 migration adds an idempotency table (not yet wired).
- Three Mockito unit tests for blocked, allowed and database-unavailable states; no execution evidence.

## Critical gaps
1. **No cross-app enforcement:** Collectra and App-B resource servers do not consume the ledger; no claims of global blocking.
2. **No Keycloak disable/logout:** new tokens can still be issued until Keycloak integration is implemented.
3. **No outbox publisher or acknowledgement:** operations remain STATE_COMMITTED, never ENFORCED.
4. **No idempotency behavior:** schema exists but block endpoint still increments version for duplicate calls.
5. **No freshness-bounded snapshot:** current synchronous DB read on each App Common request is a deliberately temporary implementation and conflicts with the target no-synchronous-control-plane-hot-path design. It fails closed on DB outage, impacting availability.
6. **No concurrency, integration or S2 proof:** real PostgreSQL + Keycloak + two-app HTTP tests remain required.

## Mandatory next tests
- Postgres transaction concurrency: two block operations, monotonic version and atomic outbox.
- HTTP: issue JWT, block subject, same JWT denied by App Common; database outage denies.
- HTTP: Collectra and App-B deny same JWT after distribution, with bounded stale snapshot and partition handling.
- Keycloak: disable account, revoke sessions and prevent refresh; record reconciliation.
- Event delivery: outbox retry, crash recovery, duplicate/out-of-order events, per-consumer ack and PARTIAL state.
- API: idempotency key same payload returns same operation; changed payload returns 409.

## Gate
Do not use R1.6 as production global revocation. Independent S2 and reproducible integration evidence required. Main untouched.
